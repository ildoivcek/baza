# Лабораторна робота №4 — Back-End з базою даних

REST API на Flask + MySQL для бази `bunny_village` (кролики, породи, іграшки).
Архітектура: Controller → Service → DAO.
Зв'язки: породи → кролики (1:M), кролики ↔ іграшки (M:M через `rabbit_toys`).

## Запуск

1. Створити базу та тестові дані:
   ```
   mysql -u root -p < init_db.sql
   ```
2. У `config/db.py` вказати пароль від MySQL (за замовчуванням порожній).
3. Встановити залежності та запустити сервер:
   ```
   pip install -r requirements.txt
   python app.py
   ```
   Сервер працює на http://127.0.0.1:5000

## Маршрути

| Метод  | URL                      | Опис                                   |
|--------|--------------------------|----------------------------------------|
| GET    | /rabbits                 | усі кролики (разом з назвою породи)    |
| POST   | /rabbits                 | додати кролика                         |
| PUT    | /rabbits/<id>            | оновити кролика                        |
| DELETE | /rabbits/<id>            | видалити кролика                       |
| GET    | /breeds/<id>/rabbits     | кролі певної породи (1:M)              |
| GET    | /rabbits/<id>/toys       | іграшки кролика (M:M)                  |

Приклад тіла для POST/PUT:
```json
{ "name": "Сніжок", "breed": "Lionhead", "age": 1, "diet": 2 }
```
Якщо породи ще немає в таблиці `breeds`, вона створюється автоматично.
